# OperCerta 面试演示脚本

本脚本只使用本地合成数据，目标时长 3--5 分钟。演示前确认 Docker Compose 健康，并在浏览器打开 `http://localhost:5173/console`。

1. 先打开公开项目专题，说明三业务是库存补货、设备维修、作业异常恢复，并指出交互生产发布门禁仍为 `CLOSED`。
2. 切换到 `/console`，选择一个场景和 `operator`；先执行“查询状态”，展示 completed、零审批、零工单，再执行“创建处置”进入等待审批。
3. 切换到 `approver`，提交绑定审批；展示审批绑定中的证据、规则版本、事实哈希、计划哈希和建议数量均来自后端事实。
4. 审批通过后展示最终状态、唯一工单 ID 和审计时间线；强调重复请求返回同一工单，而不是生成第二条写入。
5. 解释两项自动化证据：并发审批只有一个原子胜者；API/MCP 重启后从 PostgreSQL 与 LangGraph checkpoint 恢复。
6. 展示真实模型证据摘要：三业务 6 个代表 operation、3 条真实模型路径；强调模型只解释，且原文/token/费用没有被虚构记录。
7. 结束时明确边界：真实模型只完成本地代表性运行；生产 IAM/SSO、公开交互 HTTPS 后端、自动部署和 Release Tag 尚未完成，公开专题不提供可写服务。

录制视频时只保留浏览器业务区域，不展示本机用户名、文件路径、令牌、数据库连接或环境变量。只有实际完成上述流程的录屏才能放入公开专题；失败或未验证的运行不得剪辑成成功结果。
