## 可复盘的工程经验

### 1. “冻结依赖”不等于“任意阶段都能离线”

`uv.lock` 冻结项目运行依赖，但 PEP 517 build-system 解析还需要 `pyproject.toml` 中的 Hatchling。第一层 `--no-install-project` 不会保证这个构建后端进入缓存，因此第二层在全新 runner 上强制 offline 会失败。本机缓存命中不能代替 clean CI 证明。

### 2. 必须区分局部门禁和总门禁

PR #25 的后端 682、前端 62、Python 和仓库安全都通过，但 main 总 run 因 Compose 失败仍是红色。不能把“核心测试通过”写成“工程门禁全部通过”。

### 3. 架构术语必须能够映射到源码

当前没有独立生成完整计划再执行的严格 Plan-and-Execute 阶段。模型根据 Observation 逐轮选择只读工具，更准确的说法是“有界 ReAct 风格 Tool Loop”；工具/模型预算、ToolPolicy、确定性规则和审批形成安全边界。

### 4. 评测数字要带样本边界

9/9 Kimi 结果可以证明固定本地路径中的 Goal、工具、证据、审批和副作用契约，但不能外推生产准确率、成本或 SLA。端到端 P50/P95 也不能冒充模型单次推理延迟。
